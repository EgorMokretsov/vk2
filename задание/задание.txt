
На облаке лежит файл со списком городов, которые понадобятся в задании.
Само задание заключается в следующем:
1. Загрузите список городов из файла в память. 2. Для каждого уникального города получите Данные через API https://wttr.in/{City}? format=j1
3. Создайте модель WeatherData, обязательно содержащую поля: Город, Текущая температура в градусах Цельсия, Страна
4. Определите и выведите полученную информацию по каждому городу. Пример вывода: Tokyo, Japan +18 °C
5. Сгруппируйте города по странам и выведите для каждой страны: количество городов;
среднюю текущую температуру; минимальную и максимальную температуру.
Пример вывода: Japan - 3 cities, avg: +19°C, min: +16°C, max: +22 °C
Решение можно выполнить в одном из двух вариантов:
• скрипт на Python
• консольное приложение на C#
Ограничения:
• Для работы с JSON:
C# - разрешено использовать
System.Text.Json
или
Newtonsoft.Json
Python - разрешено использовать стандартный модуль
json
Другие внешние пакеты запрещены.
• Все необходимые значения необходимо вычислять кодом.
